# Keep both tools without double authority

Keep the existing [CLAUDE.md](../../CLAUDE.md) and [shared guidance](../../.claude/repository-guidance.md) intact in this book. [First 15 minutes](../start/first-15-minutes.md) copies the separate [coexistence example CLAUDE.md](../../examples/coexistence/CLAUDE.md) and its relative import, three book skills and one reviewer agent into a lab. It does not replace the book's root or add Git metadata, hooks or plugins. In your own repository, retain **its own** CLAUDE and audit `.claude` files before adding `AGENTS.md`; one canonical policy with narrow imports beats two drifting copies. Other scoped instructions in the example are for inspection, not to install as policy.

If you test coexistence with a real authorized Copilot installation, record version, attached instruction files, a matching vs nonmatching path and subagent selection. Do not let a sentinel prompt edit credentials or probe external systems. Keep user-only settings local. A scoped instruction can contradict an always-on instruction; reconcile the human requirement first and then test, rather than betting on inferred priority. [Compatibility](compatibility.md) explains imports and version caveats.
