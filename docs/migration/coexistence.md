# Keep both tools without double authority

Leave the repository's root [CLAUDE.md](../../CLAUDE.md) and [shared guidance](../../.claude/repository-guidance.md) intact. They govern maintenance of this teaching repository. First-15-minute `--with-config` explicitly copies a **single reviewed fixture CLAUDE.md with its relative import**, three canonical skills and one reviewer agent to the owned lab; it neither replaces the repository root nor copies the conflicting `.claude/CLAUDE.md`/rules/path instructions. Bare lab setup copies none. No GitHub remote, plugin or hook is needed. When migrating another repository, audit existing `.claude` files before adding `AGENTS.md`; one canonical policy with narrow imports beats two drifting copies. Other fixture instructions in [examples/coexistence](../../examples/coexistence/CLAUDE.md) are *data*, not auto-loaded root configuration.

If you test coexistence with a real authorized Copilot installation, record version, attached instruction files, a matching vs nonmatching path and subagent selection. Do not let a sentinel prompt edit credentials or probe external systems. Keep user-only settings local. A scoped instruction can contradict an always-on instruction; reconcile the human requirement first and then test, rather than betting on inferred priority. [Compatibility](compatibility.md) explains imports and version caveats.
