# Mental model: four independent controls

Claude Code habits transfer by **outcome**, not by identical command name. Copilot has (1) planning mode, (2) autonomy, (3) permissions, and (4) parallel workers. `/plan` investigates and produces a reviewable plan; it does not make the operating system read-only. `/autopilot` changes how turns continue, not which paths or websites are safe. `--available-tools` hides tools from the model; `--allow-tool` approves invocation, path verification and URL grants are additional checks. `/fleet` changes scheduling; it does not confer authority. A written acceptance oracle and human review apply in every mode. [source:cli-reference]

The [first lab](../start/first-15-minutes.md) is ordinary Python with no Git repository or remote. Offline checks require no Copilot login; live prompts do. In a Copilot session, inspect `/instructions` for the copied `CLAUDE.md`. Copilot entitlement does not imply GitHub repository hosting or grant a GitLab token. See [hosting boundaries](../hosting/capability-boundaries.md).

Start from [bounded inventory](configuration-inventory.md), select one [scenario](../scenarios/index.md), and stop at the first failed deterministic check. Reproduction and tests outrank a convincing generated summary. Copilot's local transcript, Git revision, task list and published review are different objects; none should be described as another. Source/help observations from v1.0.89 are tagged in [versions](../reference/versions.md); paid runtime behavior remains untested here.
