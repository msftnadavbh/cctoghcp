# Inventory before conversion

`python3 -B -m scripts.inventory . --json` passively enumerates bounded known paths and field names. It does **not** evaluate instruction priority, run hook handlers, initialize MCP, authenticate, or prove a configuration supported. Known JSONC locations are **reported as unparsed**; no general JSONC parser is shipped. Inspect repo and user configuration separately; don't paste secrets or private home paths into a report. Record path, owner, purpose, desired outcome, proposed destination, applicability, and whether anyone verified attachment. [source:cli-config-reference]

Carry over a small shared subset only: `companyAnnouncements`, `disableAllHooks`, `enabledPlugins`, `extraKnownMarketplaces`, and `hooks` require their individual semantics reviewed. Audit existing Claude `.mcp.json` as a separate source; do not assume it activates as Copilot's `.github/mcp.json`. Never map Claude permissions, provider configuration or local secrets by generic JSON copy. Root `CLAUDE.md` remains the repository instruction file; first-15-minute **configured** lab copies its own canonical fixture `CLAUDE.md`, while bare setup copies none. A second root `copilot-instructions.md` is unnecessary here. [Configuration map](../reference/configuration-map.md) and [coexistence](coexistence.md) show where each surface belongs.
