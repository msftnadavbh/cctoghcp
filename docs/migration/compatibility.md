# Compatibility is not precedence

Copilot documentation recognizes root `CLAUDE.md`, `.claude/CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, GitHub custom instructions and path instructions; v1.0.89 release notes add `.claude/rules`. Do not infer that every competing file has a universal precedence or that nested content loads for unrelated files. The coexistence fixtures under [examples/coexistence](../../examples/coexistence/CLAUDE.md) deliberately contain competing clues; ask an authorized session to report attached files and an innocuous sentinel while visiting both matching and nonmatching paths, then compare actual behavior. Fixture checks are not runtime precedence evidence. [claim:rules-added] [source:cli-reference]

Repository-relative `@` imports are bounded by repository/custom instruction boundaries; do not use absolute paths or `~` as an implicit import escape. Imports are not expanded in `GEMINI.md` or `.github/instructions/*.instructions.md`. Restart or resume and inspect `/instructions` after editing; do not promise arbitrary hot reload. The current Claude AGENTS.md behavior also depends on Claude version (direct support at least 2.1.277 per supplied research; check the installed Claude version before relying on that threshold). Never sell an AGENTS migration as mandatory for every Claude version. [source:instructions-reference]

For a new custom subagent, explicitly choose `include-custom-instructions: true` to include repository instructions; selection of an agent as the main agent is not the same as subagent inheritance. [Existing read-only agents](../../examples/agents/focused-investigator.agent.md) declare `view`, `grep`, `glob`, not shell. Discovery/priority descriptions differ between reference and overview, so inspect `/env` and actual attached instructions when names collide rather than asserting one global order. [Known discrepancies](../reference/known-discrepancies.md).
