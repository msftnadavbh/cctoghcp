# GitHub later: separate capability lane

Capabilities in this page require a GitHub target host and are **not prerequisites** for local Copilot use with a GitLab source remote. Do not add a GitHub remote merely to satisfy examples. `/delegate` and cloud agent tasks can checkpoint a local branch and create a draft PR; external effects and branch state require approval. The GitHub-only optional `.github/workflows/copilot-setup-steps.yml` prepares a cloud agent environment **only when present on the default branch** with a `copilot-setup-steps` job; merely mentioning the filename here creates no job, schedule, issue agent or permission. This repo does not install that workflow. [source:github-copilot-setup-steps] [claim:setup-steps]

`gh agent-task create/list/view` requires gh >=2.80 in the public-preview offering according to supplied research; observed gh 2.45.0 cannot be claimed to support it. The [current gh manual](https://cli.github.com/manual/gh_agent-task) confirms the preview command surface, not availability in our binary. PR review and Copilot approvals are separate from `/review` on a local diff; preview approval settings and a human reviewer remain project decisions. GitHub remote-control/export is a session service and may run from a non-GitHub working directory; it is not evidence that the source remote changed. See [sessions](../workflows/sessions-and-context.md) and [hosting boundaries](capability-boundaries.md). [source:github-agent-tasks]
