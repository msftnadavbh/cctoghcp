# GitHub-hosted capabilities: cloud delegation and PRs

These capabilities apply **if the target repository is hosted on GitHub**; they are not prerequisites for local Copilot CLI work on any host. Do not add or change a remote merely to satisfy examples. `/delegate` and cloud agent tasks can checkpoint a local branch and create a draft PR; external effects and branch state require approval. The optional [cloud-agent setup workflow](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/customize-the-agent-environment) `.github/workflows/copilot-setup-steps.yml` requires a `copilot-setup-steps` job on the default branch. This repo does not install it.

For public-preview `gh agent-task create/list/view`, check your installed `gh` version and the [current manual](https://cli.github.com/manual/gh_agent-task) before use. PR review and Copilot approvals are separate from `/review` on a local diff; preview approval settings and a human reviewer remain project decisions. GitHub remote-control/export is a session service and may run from a non-GitHub working directory; it does not change the source remote. See [sessions](../workflows/sessions-and-context.md) and [hosting boundaries](capability-boundaries.md).
