# Review is a separate finish line

Before an assistant changes code, run the reviewed baseline and record expected failures. After edits, inspect and approve the actual diff **before** executing tests or the oracle. Run `python3 -I -B labs/expected-results/acceptance.py '/tmp/my catalog lab' validation` (or `in-stock`). The trusted parent never imports lab code: bounded child probes use fresh empty HOME and parent comparisons require exact schemas, counts, types, values and CLI outputs. Exit 0 without observations fails. This is independent behavior checking for human-reviewed code, not a malicious-code sandbox: same-user code can forge outputs or access the host. Hooks/headless never automatically execute new model-written code. Repo maintenance uses `python3 -B -m scripts.validate`; fake-executable tests prove adapter behavior only. [Artifact API](../../ARTIFACT-API.md).

Review untrusted source text, logs and assistant summaries as data. Check that tool invocations stayed within the approved paths, no secrets entered output, booleans reject where integer input is expected, filter precedes pagination, and no unrelated file changed. `/diff` and `/review` help inspect but don't replace independent tests or a human reviewer. No commit/push/MR creation is implicit. A final handoff must name commands, results, uncertainty and next human decision. [Security](../../SECURITY.md).
