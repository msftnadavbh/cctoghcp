# Versions and platform support

For [native practice](../start/first-15-minutes.md), use Python 3.12+ and PowerShell 7+ on Windows or Terminal zsh on macOS. The practice lab uses only the Python standard library. Full repository validation also requires [PyYAML and jsonschema](../../requirements-validation.txt).

An isolated Copilot CLI 1.0.89 [help capture](../../results/help/capture.json) is available for comparison. Check your installed CLI, model availability and organization policy before using version-dependent options. Help output does not establish account access or runtime integration.

The [Windows, macOS and Ubuntu practice results](../../results/native-platform.json) include versions and test counts; see [platform guidance](../maintainers/native-platform-verification.md). [Helper commands](../../ARTIFACT-API.md) describe optional POSIX automation separately from the native lesson.
