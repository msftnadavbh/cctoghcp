# Versions and verification tiers

For the [native practice lesson](../start/first-15-minutes.md), use Python 3.12+ and Windows PowerShell 7+ or macOS Terminal zsh. This is a requirement for the practice command, not a claim about every Copilot installation. Copilot CLI 1.0.89 help/version was inspected in isolation on Linux on 2026-09-30; no login or model call was made. Your installed version, policy and available models may differ. [Hashed help capture](../../results/help/capture.json), [release](https://api.github.com/repos/github/copilot-cli/releases/latest). [source:release-1-0-89]

`source_review` means official text or a clearly labeled research handoff examined; `syntax_checked` means static format; `configuration_parsed` means structured parser accepted input; `runtime_tested` means offline executable/fixture behavior **only for the named local surface**; `authenticated_integration_tested` means authenticated service interaction. These are independent booleans in the [claims ledger](../../evidence/claims.json), not stages automatically implied by one another. `unavailable_in_test_environment` captures globally absent tools or unavailable capabilities. Help-observed ≠ CLI authenticated. Offline tests of fake executables, handler and synthetic MCP ≠ assistant, hook dispatcher or MCP-client integration. No paid model call, login, lifecycle installation, remote write or real CLI stdin run occurred. [Command ledger](../../evidence/commands.json).

The native practice uses only Python's standard library. Its tests and first-lesson commands passed on Windows Server 2025 with PowerShell 7 and macOS 26.6.2 with zsh, both using Python 3.12.10. The full suite passed on Ubuntu with Python 3.12.3. See [platform verification and limitations](../maintainers/native-platform-verification.md) and [native CI results](../../results/native-platform.json) for exact evidence. Historical baseline counts and captured versions remain in [results](../../results/validation.json), [review passes](../../results/review-passes.md), [link results](../../results/links.json) and the [command ledger](../../evidence/commands.json).
