# Troubleshoot configuration differences

If a documented option differs from your installed help, check [your version](versions.md) and account policy before changing permissions.

| Symptom | Next step |
| --- | --- |
| Competing agent or instruction files | Restart, inspect `/agent`, `/instructions` and `/env`, then compare attached content for the relevant path. Keep `@` imports repository-relative in supported files; `GEMINI.md` and path instructions do not expand them. [Instructions](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-custom-instructions) |
| Narrow noninteractive permission rejected | [Programmatic docs](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-programmatic-reference) describe selective grants, while [captured help](../../results/help/help.txt) requires `--allow-all-tools`. Use interactive manual approvals or stop; do not widen grants to make a run succeed. |
| `--allow-tool=read` absent from permissions help | Compare [programmatic docs](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-programmatic-reference) and [your installed help](../../results/help/permissions.txt); review actual requests manually. |
| Autopilot continues after task | Inspect `/settings` and `stayInAutopilot`; change it deliberately if needed. |
| Write rule unexpectedly broad | `write(path)` can match trailing components, and shell tools can write independently. Review exact paths and shell grants. |
| GitLab MCP not offered | [Beta preview](https://docs.gitlab.com/user/model_context_protocol/mcp_server/) requires instance/group availability; confirm client support separately. |
| Plugin local install differs from docs | Compare [plugin reference](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-plugin-reference) with installed `plugin install --help`; inspect the package before approving installation. |
| Scoped `.claude/rules` missing | Check your version and `/instructions` for the target path. |
| AI-credit limit scope differs | The [dedicated public-preview guide](https://docs.github.com/en/copilot/how-tos/copilot-cli/use-copilot-cli/set-session-limit) says `/limits set max-ai-credits NUMBER` applies across an interactive session; the [command reference](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-command-reference) calls it per-response, resetting at each user message (and describes `--max-ai-credits` that way). Captured [1.0.89 config help](../../results/help/config.txt) says session scope, as did a local **help-only** 1.0.90 check on 2026-10-02; neither is an authenticated runtime test. The limit remains **soft** regardless of scope: an in-progress response can exceed the value. Check your installed help and observed `/usage`; do not rely on a session-wide hard ceiling. [Token economy](../workflows/token-economy.md). |
| Autopilot continuation default differs | The [Autopilot concepts guide](https://docs.github.com/en/copilot/concepts/agents/copilot-cli/autopilot) says five automatic continuation messages by default; the [command reference](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-command-reference) says unlimited. Captured [1.0.89 help](../../results/help/help.txt) says five, as did local **help-only** 1.0.90 checks on 2026-10-02; neither proves runtime behavior across versions. Specify `--max-autopilot-continues COUNT` explicitly on launch and inspect installed help; it counts continuation messages, **not** model calls, tools, time or credits. [Autopilot](../workflows/autopilot.md). |

The 1.0.90 checks used `copilot --version`, `copilot --help` and `copilot help billing`, without authentication or model calls. They supplement, rather than replace, the repository's captured 1.0.89 baseline.
