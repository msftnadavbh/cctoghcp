# Ten reviewed external patterns: adapt, never auto-install

Upstream [awesome-copilot](https://github.com/github/awesome-copilot) offers optional examples, not configuration to install wholesale. Its index and the [Creating Effective Skills](https://awesome-copilot.github.com/learning-hub/creating-effective-skills/) article were reviewed; the ten entries below were **not** all fetched or pinned to a revision. Check the specific content, license and version before copying into your project. The upstream repository lists MIT at root, but contributed items can require additional attribution. [Upstream index](https://awesome-copilot.github.com/llms.txt). [source:awesome-copilot]

If adapting, inspect changing main-branch text, shell steps, MIT attribution and edit scope |

These are **decisions** for this teaching repo: keep linked patterns as sources; implement no second planning framework, no third-party agent, no active hook/plugin/CI workflow and no vendored upstream copy. The [local canonical skills](../../.claude/skills) remain the only packaged instructions; their plugin ZIP is still inert. Upstream index and Learning Hub were retrieved after Context7 returned quota exhausted for this turn, with official GitHub/GitLab docs used for specific syntax. [Provenance](../../SOURCES.md).

Related optional projects are deliberately out of scope: [Copilot SDK](https://github.com/github/copilot-sdk) (a CLI-backed lifecycle/events option after a *real* wrapper interoperability test, not a dependency here); [spec-kit](https://github.com/github/spec-kit) (more spec scaffolding if a reviewed twelve-field plan fails a real team need); [gh-aw](https://github.com/github/gh-aw) (GitHub Actions agents with separate scheduler/credential approvals); [HydraFusion announcement](https://github.blog/ai-and-ml/github-copilot/project-hydrafusion-frontier-quality-via-multi-model-orchestration/) and [traces research](https://github.com/samueltauil/hydrafusion-traces) (research-only, no promised CLI trace API). None was installed or exercised in this repository.
